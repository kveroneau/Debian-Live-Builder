Originally built for my *Hacker's Edge* custom Linux distribution project, which hasn't gone anywhere in several years.

This program is currently a Lazarus front-end, and is very primitive and on the edge of just being a prototype, but I still use this to generate my current `live-build` config trees to generate my current Debian immutable images I use each and every day.

There is a set of modules you can reference in the `mods` directory to see how these modules are put together.

There will also be some documentation under `docs` as well.
